# The sheet field's GPU suites. No CI runner can admit the sheet field (lavapipe is too slow for the march's work
# budget; the CI lavapipe job tests that refusal), so these run on a real GPU machine, which writes a GPU receipt
# for the tree it ran (scripts/gpu_receipt_run.py, which measures the adapter itself and refuses a software one).
# Any hardware adapter of a GPU notebook machine can write it; the receipt names the adapter it measured. The
# CI evidence receipt of a landing that touches a path below needs that receipt for the landing tree with every suite
# at rc 0 and at least its min passing tests (the landing tool's GPU receipt rule, which also applies the base's rule,
# so deleting or weakening this file needs the receipt too), and scripts/ci_test_coverage_check.py counts these suites
# as run there. The hand-kept paths are the sheet field, its tests and examples, the dependency versions (wgpu, naga)
# and this rule with its runner. The reach block lists every other crate file those files reach, transitively
# (crate paths, re-exports, included shaders; the CPU evaluator is also the suites' parity reference); it is
# generated by scripts/gpu_receipt_reach.py --write-reach, and that check fails when it differs from the walk.
